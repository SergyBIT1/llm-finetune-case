# Qwen2.5-3B — извлечение вакансий из Telegram-постов (QLoRA)

LoRA-адаптер для Qwen2.5-3B-Instruct: классификация постов Telegram-каналов
(вакансия / не вакансия) и извлечение полей в строгий JSON.

Учебный прогон fine-tuning, сделанный как практический кейс под собственный
инструмент (сборщик вакансий из Telegram-каналов).

## Задача

Вход: текст поста. Выход: JSON
`{"is_vacancy": bool, "title", "salary", "format", "employment", "contact"}`.
Негативы в обучении: реклама курсов, резюме соискателей (трудный негатив),
продажи, новости, спам.

## Данные

500 примеров ChatML (440 train / 60 val): синтетика в 3 стилях + трудные
негативы (резюме соискателей, реклама курсов, продажи, новости, спам),
дедупликация, сбалансированные классы. Генератор — `make_dataset.py`.

## Вариант A — целевой (GPU, Qwen2.5-3B, QLoRA)

Основной сценарий из `train_unsloth.py`, для Google Colab (T4):

- База: unsloth/Qwen2.5-3B-Instruct (4bit)
- Метод: QLoRA через Unsloth; LoRA r=16, alpha=32, dropout=0,
  таргеты: q/k/v/o/gate/up/down
- Обучение: 3 эпохи, lr 2e-4 (cosine, warmup 5%), batch 4 × grad_accum 4,
  seed 42, max_len 1024
- Loss: train/val по эпохам — заполняется после прогона в Colab

## Вариант B — воспроизведённый локально (Apple M1 Pro, MPS)

Прогон без GPU через `train_local.py` (обычный PEFT-LoRA, без 4bit/Unsloth),
чтобы получить реальные метрики там, где CUDA недоступна. Модель уменьшена,
чтобы прогон завершался за минуты:

- База: Qwen/Qwen2.5-0.5B-Instruct (fp32, MPS)
- LoRA r=16, alpha=32, dropout=0, те же таргеты; trainable 8.8M / 502M (1.75%)
- 1 эпоха, lr 2e-4 (cosine), batch 1 × grad_accum 8, max_len 256, seed 42,
  подвыборка train=200 (полный val=60)
- **Loss:** train 2.25 → 0.61, финальный train_loss 1.22, **eval_loss 0.40**
  (одна эпоха; полные метрики — в `results/metrics.json`)

Примеры ответов обученного адаптера (`results/samples.txt`):

```
ПОСТ: Срочно нужен ассистент в онлайн-школу! Удалёнка, оплата 35 000 р. @school_hr
ОТВЕТ: {"is_vacancy": true, "title": "ассистент", "salary": "35 000 р.",
        "format": "удаленно", "employment": "отклик", "contact": "@school_hr"}

ПОСТ: Заработок на криптовалюте без вложений! Пиши + в личку
ОТВЕТ: {"is_vacancy": false, "title": null, ... }   ← спам отсеян верно
```

## Ограничения

Датасет синтетический и небольшой — прогон демонстрирует пайплайн
(данные → обучение → оценка → публикация), а не production-качество.
Локальный вариант (0.5B, 1 эпоха, подвыборка) уверенно ловит is_vacancy и
основные поля, но на мелких полях (employment) ошибается — ожидаемо для такой
модели и бюджета обучения. Следующие шаги: полный прогон 3B на GPU, реальные
размеченные посты, расширение схемы полей, сравнение с few-shot базовой модели.
